[[The task||任务定义]]

[[Process a set of 100 full-text biomedical papers (PMC, JATS XML).||处理 100 篇生物医学全文文献（PMC，JATS XML）。]]

[[Task 1 · Gene and disease extraction||任务 1 · 基因与疾病实体抽取]]

[[Extract all gene and disease mentions from each paper and output the identified entity lists, if any.||抽取每篇论文中提及的所有基因与疾病名称，并输出识别出的实体列表（如有）。]]

[[Task 2 · Gene–disease relationship analysis||任务 2 · 基因–疾病关系分析]]

[[For paper i with Ni genes and Mi diseases, evaluate all Ni × Mi candidate pairs. Link a pair if the paper provides evidence of an association, correlation, or causal relationship, yielding a gene–disease bipartite graph per paper.||对含 Ni 个基因与 Mi 个疾病的第 i 篇论文，评估全部 Ni × Mi 个候选配对；若原文提供关联、相关或因果关系的证据则建立连边，最终构建每篇论文的基因–疾病二部图。]]

[[Our extensions: every link is paired with its supporting sentence(s) and annotated as a novel study finding or background knowledge, while weak evidence is flagged uncertain rather than linked.||我们的扩展：每条连边均附有原文支撑句，并标注为本研究新发现或背景知识；弱证据配对标记为 uncertain 而不建立连边。]]

[[Experiment workflow design||实验流程设计]]

[[Baseline: PubTator3. Models evaluated in blind tests: Claude Opus 5.5, GPT-6.1 Sol, and GPT-6 Astra.||对比基线：PubTator3。盲测评估模型：Claude Opus 5.5、GPT-6.1 Sol 与 GPT-6 Astra。]]

[[Codify the extraction workflow and decision criteria in a standardized skill.md.||在标准化 skill.md 中明确定义抽取流程与判定准则。]]

[[Evaluate the paper in fresh, unprimed sessions using only the written rules.||在无先验上下文的全新会话中，仅依据书面规则独立重测。]]

[[A contract validator verifies every quote, character offset, and table.||格式校验器自动核验每条引文、字符偏移量与输出表格。]]

[[Method development||方法构建与演进]]

  • [[Reviewed existing systems and selected PubTator3 as the comparison baseline.||调研现有系统，选定 PubTator3 作为对比基线。]]
  • [[Developed extraction rules across 5 pilot papers (iterating from Skill 1.0 to 1.3) and curated 35 boundary cases to validate rule consistency.||基于 5 篇试点论文制定抽取规则（由 Skill 1.0 迭代至 1.3），并构建 35 个边界案例以验证规则一致性。]]
  • [[Distilled the full rule specification into a compact decision card to reduce token overhead and interaction turns, preserving fidelity to the full rules (110/112 boundary-case decisions agree, stable across 3 runs).||将完整规则精炼为紧凑的判定卡（decision card）以缩减 token 开销与交互轮次，并验证其与完整规则高度一致（110/112 个边界案例判定吻合，且跨 3 次运行保持稳定）。]]
  • [[Evaluated prompt and reasoning variants via a controlled A/B test on a frozen set of 12 papers.||在固定的 12 篇测试集上通过受控 A/B 测试评估不同规则与推理配置。]]
  • [[Deployed the selected configuration across all 100 papers and benchmarked zero-shot accuracy on the expert-annotated BioRED corpus.||将最终配置部署于全部 100 篇论文，并在专家标注的 BioRED 基准语料库上评估准确率。]]

[[Key optimizations||核心优化措施]]

  • [[Tracked model behavior across 5 baseline papers before and after each optimization.||在 5 篇基准论文上持续追踪每次优化前后的模型行为一致性。]]
  • [[Offloaded text-span lookup and character-offset calculation to a deterministic local toolkit.||构建确定性本地工具包，接管文本跨度定位与字符偏移量计算。]]
  • [[One initial extraction request, with at most one validation-triggered repair, replaces multi-turn agent interaction.||以一次初始抽取请求加至多一次校验触发的修复，替代多轮 agent 交互。]]
  • [[Compressed the skill rules (input 20k → 9k tokens) and served them as a cached system prompt.||精简 skill 规则（输入由 20k 降至 9k tokens），并作为缓存系统提示词复用。]]

[[Output token reduction||输出端精简]]

  • [[Restricted the output schema to essential fields: entities, evidence, and pairs.||输出结构仅保留核心字段：实体、证据与候选配对。]]
  • [[The model cites sentence numbers rather than verbatim quotes; a post-processing script reconstructs exact quotes and offsets from the source text.||模型仅输出句子编号而非复制原文；后处理脚本自动回填原文引文并计算精确字符偏移。]]
  • [[Segmented extra-long documents (e.g., conference proceedings) into manageable chunks.||对超长文献（如会议论文集）进行分块处理。]]

[[How one request replaces multi-turn interaction||单次请求如何替代多轮交互]]

1[[Script packs the input||脚本组装输入]]

[[Packages the rules, numbered paragraphs and sentences, and output schema into one prompt.||将判定规则、编号段落与句子以及输出格式组装为单条提示词。]]

2[[Model answers once||模型单次作答]]

[[Generates a concise structured judgment without tool calls, file reads, or shell commands.||直接生成紧凑的结构化判定，无需调用工具、读取文件或执行命令。]]

3[[Script does the rest||确定性后处理]]

[[The toolkit resolves entity mentions, computes offsets, populates the gene × disease matrix, and validates the output schema.||工具包自动解析实体跨度、计算偏移量、补全基因 × 疾病矩阵并执行格式校验。]]

4[[One repair, only on error||按需单次修正]]

[[If validation detects errors (e.g., a mismatched citation), the error report is returned to the model once for targeted correction.||若校验发现异常（如引文不匹配），仅将错误报告发回模型执行一次定向修正。]]
