# Skill 维护约定

- 本目录是受 Git 管理的唯一维护源；安装位置见 `registry.json`。不要直接编辑个人 Skills 中的安装副本，也不要用旧副本覆盖新版本。
- 开始修改前运行 `manage_skill.py status`，检查已安装版本、文件差异和 Git 状态。若安装副本有未登记修改，先保留并核查，不能强行同步。
- 规则或包内容变更必须递增 `SKILL.md` 的版本、更新包内 CHANGELOG，并提交/tag；同版本不同内容不允许覆盖安装。
- `manage_skill.py install` 默认仅预览；`--apply` 才执行。它会拒绝降级、同版本覆盖及未知安装端修改，安装前归档两边。
- 既有1.0.0、1.1.0标签是历史导入；1.2.0及1.3.0按已确认讨论修订，但结构/引文检查不等于语义验证。未经用户要求不顺带修订规则、重跑论文或启动其他模型测试。
- 不改原论文或旧分析结果。此 Git 仓库只覆盖 skills 目录，不自动提交或上传整个实验项目。
